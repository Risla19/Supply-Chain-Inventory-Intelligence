# Supply Chain & Inventory Intelligence

## Project Overview
This project analyzes inventory levels, replenishment requirements, warehouse performance, and demand forecasting using business intelligence and data analytics tools.

## Tools & Technologies
- Microsoft Excel
- SQL Server
- Power Query
- Power BI and DAX
- Python (Pandas, Matplotlib, Scikit-learn)

## Key Features
- Inventory value and stock-level analysis
- Reorder risk and replenishment analysis
- Warehouse and SKU performance dashboards
- Demand trend analysis
- Baseline forecasting and model accuracy evaluation

## Project Structure
- `01_Data` — Dataset files
- `02_SQL` — SQL queries
- `03_PowerBI` — Power BI dashboard
- `04_Python_Forecasting` — Forecast outputs and charts
- `05_Documentation` — Project findings

## Project Status
Portfolio project in progress.

## Project Objectives
- Analyze inventory levels and inventory value across warehouses and SKUs.
- Identify items requiring replenishment.
- Evaluate warehouse inventory coverage against forecast demand.
- Visualize inventory risks and key performance indicators using Power BI.
- Compare simple forecasting methods using Python and evaluate prediction errors.

  ## Key Results
- Analyzed 91,250 supply chain records.
- Built interactive Power BI dashboards for inventory value, stock risk, SKU performance, and warehouse analysis.
- Created Python daily-demand forecasts and compared two simple forecasting methods.
- The baseline average model achieved a Mean Absolute Error (MAE) of 671.32 units per day, outperforming the 7-day moving-average model (743.93 units per day).

## Limitations
- The dataset represents simulated supply chain data, not verified records from a real company.
- The forecasting models are simple baselines and should be improved before being used for operational decisions.
